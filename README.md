# Dr. Maya Reynolds — Clinical Psychology Practice Website Redesign

A high-end, responsive single-page practice website designed for **Dr. Maya Reynolds, Psy.D.** (Clinical Psychologist based in Santa Monica, CA). This project is a complete homepage redesign featuring custom theme styling, authentic copy alignment, and custom interactive React components while preserving the foundational layout structure of the original template.

## 🎨 Project Overview & Redesign Strategy

This project reimagines a standard practice template into a warm, grounding, and professional digital environment tailored specifically for a clinical psychology practice. 

### Key Design & Branding Highlights:
* **Custom Theme Palette:** Built using a refined CSS variable system featuring warm alabaster, deep forest slate, and soft oatmeal tones to evoke calm, safety, and reflection.
* **Authentic Profile Alignment:** Integrated Dr. Maya Reynolds' professional background, Santa Monica office location, and clinical specialties (Anxiety & Panic, Trauma & EMDR, Professional Burnout & Perfectionism).
* **High-End Typography & Micro-Interactions:** Custom animated underline hover effects on call-to-action links and smooth anchor-based navigation.

---

## 🛠️ Key Features & Components

1. **Interactive "Our Office" Carousel:** 
   * Developed a custom React state-driven image carousel highlighting Dr. Maya's real Santa Monica consultation loft space, natural light, and quiet environment using authentic profile assets.
2. **Responsive Animated Navbar:** 
   * Features desktop navigation anchor links and a mobile view equipped with an animated hamburger-to-cross icon toggle and a smooth slide-down navigation overlay.
3. **Single-Page Smooth Scrolling Architecture:** 
   * Configured native CSS smooth scrolling (`scroll-behavior: smooth`) connecting the main sections (`#about`, `#office`, `#specialties`, `#approach`, `#services`, and `#contact`).

## 💻 Getting Started Locally

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
```bash
git clone https://github.com/Novamxter/maya-reynolds-psychology-redesign.git
```

2. **Navigate into the project directory:**
```bash
cd maya-reynolds-psychology-redesign
```

3. **Install dependencies:**
```bash
npm install
```

4. **Run the development server:**
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
